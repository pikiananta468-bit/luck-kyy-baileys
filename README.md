# Luck Kyy Baileys

WhatsApp bot sederhana menggunakan Baileys.

## Install

```bash
npm install
npm start
```

Setelah QR muncul di terminal, buka WhatsApp → Perangkat Tertaut → Tautkan Perangkat lalu scan QR.

## Commands

- `.menu`
- `.ping`
- `.owner`
- `.runtime`

## Catatan

Folder `session/` sengaja tidak di-upload ke GitHub karena berisi kredensial sesi WhatsApp.
Gunakan bot secara wajar dan jangan melakukan spam/bulk messaging.
